# レシピ管理アプリ

レシピを追加・管理できるWEBアプリケーション

## 📋 機能

### ✅ Phase 1 MVP (完了)
- レシピの登録・編集・削除
- レシピ名の登録（必須）
- フラット構造の材料登録（名前、分量、単位）
- 倍率ベースの分量調整機能
- シンプルな作り方の登録（テキスト）
- LocalStorageによるデータ永続化
- レシピ一覧表示

### ✅ Phase 2: 階層構造対応 (完了)
- **階層構造の材料登録**（最大3階層）
  - グループ化による材料の整理
  - グループ内に材料やサブグループを追加
  - インデント表示で階層を視覚化
- **構造タイプの選択**
  - フラット構造 vs 階層構造を選択可能
  - 既存データの自動変換（後方互換性）
- **階層表示の詳細ページ**
  - グループと材料を階層的に表示
  - レベル表示（Lv1, Lv2, Lv3）

## 🚀 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **状態管理**: React Context + Hooks
- **データ保存**: LocalStorage

## 🎯 使い方

### レシピの作成

1. トップページの「新規作成」ボタンをクリック
2. レシピ名を入力（必須）
3. **構造タイプを選択**
   - **フラット構造**: すべての材料を同一階層で管理
   - **階層構造**: グループで材料を整理（最大3階層）
4. 材料を追加
   - **フラット構造の場合**: 「材料を追加」ボタンで材料を追加
   - **階層構造の場合**:
     - 「グループを追加」でグループを作成
     - グループ内に「材料を追加」または「サブグループ」を追加
     - 階層レベル（Lv1〜Lv3）が自動表示
5. 分量調整倍率を設定（デフォルト: 1倍）
6. 作り方を入力（任意）
7. 「作成する」ボタンをクリック

### レシピの閲覧

- トップページでレシピ一覧を表示
- カードをクリックして詳細を表示
- 詳細ページで倍率を変更すると、材料の分量が自動計算されます

### レシピの編集

1. レシピ詳細ページの「編集」ボタンをクリック
2. 内容を変更
3. 「更新する」ボタンをクリック

### レシピの削除

1. レシピ詳細ページの「削除」ボタンをクリック
2. 確認ダイアログで「OK」をクリック

## 📁 プロジェクト構成

```
kitchen/
├── app/                    # Next.js App Router
│   ├── layout.tsx         # ルートレイアウト
│   ├── page.tsx           # トップページ（レシピ一覧）
│   ├── globals.css        # グローバルCSS
│   └── recipes/
│       ├── new/           # レシピ新規作成ページ
│       └── [id]/          # レシピ詳細・編集ページ
├── components/            # Reactコンポーネント
│   ├── RecipeCard.tsx    # レシピカード
│   ├── RecipeList.tsx    # レシピ一覧
│   └── RecipeForm.tsx    # レシピフォーム
├── lib/                   # ライブラリ・ユーティリティ
│   ├── RecipeContext.tsx # React Context（状態管理）
│   └── storage.ts        # LocalStorage操作
├── types/                 # TypeScript型定義
│   └── index.ts          # データモデル
├── SPECIFICATION.md       # 詳細仕様書
└── package.json
```
