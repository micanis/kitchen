# レシピ管理アプリ

レシピを追加・管理できるWEBアプリケーション

## 📋 機能

### ✅ Phase 1 MVP (完了)
- レシピの登録・編集・削除
- レシピ名の登録（必須）
- フラット構造の材料登録（名前、分量、単位）
- 倍率ベースの分量調整機能
- シンプルな作り方の登録（テキスト）
- LocalStorageによるデータ永続化
- レシピ一覧表示

### ✅ Phase 2: 階層構造対応 (完了)
- **階層構造の材料登録**（最大3階層）
  - グループ化による材料の整理
  - グループ内に材料やサブグループを追加
  - インデント表示で階層を視覚化
- **構造タイプの選択**
  - フラット構造 vs 階層構造を選択可能
  - 既存データの自動変換（後方互換性）
- **階層表示の詳細ページ**
  - グループと材料を階層的に表示
  - レベル表示（Lv1, Lv2, Lv3）

### ✅ Phase 3: 高度な機能 (完了)
- **SVGアイコンアップロード**
  - レシピごとにSVGアイコンを設定可能
  - Base64エンコードによる保存
  - アイコンプレビュー機能
- **複数の分量調整モード**
  - 人数ベース: 基準人数から自動計算
  - 材料ベース: 特定材料の分量を基準に全体を調整
  - 倍率ベース: シンプルな倍率での調整（従来方式）
- **ステップバイステップの作り方**
  - 番号付きステップ表示
  - 各ステップに所要時間を設定可能
  - 総所要時間の自動計算
  - マークダウン形式との切り替え可能
- **検索・フィルター・ソート機能**
  - レシピ名・材料名での検索
  - 構造タイプでのフィルタリング
  - 名前・作成日でのソート
  - アクティブフィルターの可視化とクリア機能

### ✅ Phase 4: 完成度向上 (完了)
- **レスポンシブデザイン最適化**
  - モバイルフレンドリーなレイアウト
  - タッチターゲットの最適化（44px以上）
  - 柔軟なグリッドレイアウト
  - レスポンシブなフォントサイズとスペーシング
- **アクセシビリティ改善**
  - 適切なARIAラベル追加
  - セマンティックHTML使用（article, time要素）
  - フォーカスインジケーター強化
  - キーボードナビゲーション対応
  - スクリーンリーダー対応
- **パフォーマンス最適化**
  - 検索入力のデバウンス処理（300ms）
  - React.memoによる不要な再レンダリング防止
  - useMemoによる計算結果のメモ化

## 🚀 技術スタック

- **フレームワーク**: Next.js 14 (App Router)
- **言語**: TypeScript
- **スタイリング**: Tailwind CSS
- **状態管理**: React Context + Hooks
- **データ保存**: LocalStorage

## 🎯 使い方

### レシピの作成

1. トップページの「新規作成」ボタンをクリック
2. レシピ名を入力（必須）
3. **（任意）SVGアイコンをアップロード**
   - 100KB以下のSVGファイルを選択
   - プレビューで確認
4. **構造タイプを選択**
   - **フラット構造**: すべての材料を同一階層で管理
   - **階層構造**: グループで材料を整理（最大3階層）
5. 材料を追加
   - **フラット構造の場合**: 「材料を追加」ボタンで材料を追加
   - **階層構造の場合**:
     - 「グループを追加」でグループを作成
     - グループ内に「材料を追加」または「サブグループ」を追加
     - 階層レベル（Lv1〜Lv3）が自動表示
6. **分量調整モードを選択**
   - **倍率ベース**: シンプルな倍率で調整（デフォルト）
   - **人数ベース**: 基準人数を設定して調整
   - **材料ベース**: 特定材料の分量を基準に調整
7. **作り方を入力（任意）**
   - **マークダウン形式**: 自由形式のテキスト
   - **ステップ形式**: 番号付きステップで所要時間も設定可能
8. 「作成する」ボタンをクリック

### レシピの閲覧

- トップページでレシピ一覧を表示
- **検索・フィルター機能**
  - レシピ名や材料名で検索
  - 構造タイプ（フラット/階層）でフィルター
  - 名前順・作成日順でソート
- カードをクリックして詳細を表示
- 詳細ページで分量を調整
  - **人数ベース**: 人数を変更して自動計算
  - **材料ベース**: 基準材料の分量を変更して全体を調整
  - **倍率ベース**: 倍率を変更して自動計算
- ステップ形式の作り方では総所要時間も表示

### レシピの編集

1. レシピ詳細ページの「編集」ボタンをクリック
2. 内容を変更
3. 「更新する」ボタンをクリック

### レシピの削除

1. レシピ詳細ページの「削除」ボタンをクリック
2. 確認ダイアログで「OK」をクリック

## 📁 プロジェクト構成

```
kitchen/
├── app/                    # Next.js App Router
│   ├── layout.tsx         # ルートレイアウト
│   ├── page.tsx           # トップページ（レシピ一覧）
│   ├── globals.css        # グローバルCSS
│   └── recipes/
│       ├── new/           # レシピ新規作成ページ
│       └── [id]/          # レシピ詳細・編集ページ
├── components/            # Reactコンポーネント
│   ├── RecipeCard.tsx    # レシピカード
│   ├── RecipeList.tsx    # レシピ一覧
│   └── RecipeForm.tsx    # レシピフォーム
├── hooks/                 # カスタムフック
│   └── useDebounce.ts    # デバウンス処理
├── lib/                   # ライブラリ・ユーティリティ
│   ├── RecipeContext.tsx # React Context（状態管理）
│   └── storage.ts        # LocalStorage操作
├── types/                 # TypeScript型定義
│   └── index.ts          # データモデル
├── SPECIFICATION.md       # 詳細仕様書
└── package.json
```
